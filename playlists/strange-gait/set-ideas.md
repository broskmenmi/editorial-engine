# STRANGE GAIT — Set Ideas

This is a **non-canonical DJ/set inspiration layer**.

It exists to turn discovery work into creative directions without pretending that every interesting track belongs in the canonical Spotify playlist or that an untested pair is a proven mix.

Nothing in this file changes `ledger.md`, Spotify order, `live-mixing.md`, or a REJECT/REVISIT verdict.

## Set-idea contract

A set idea may be built from:

- exact tracks in the discovery pool;
- artists or labels whose catalogues suggest a useful direction;
- release watches and unresolved research leads;
- canonical STRANGE GAIT tracks as reference points.

Every idea must state:

1. **Direction** — the creative world or arc being explored.
2. **Ingredients** — tracks/artists/labels worth digging through.
3. **Why it is interesting** — clearly marked as editorial hypothesis when not directly evidenced.
4. **Unknown / risk** — what is not known about energy, mixability, key, phrasing, density, or actual transition feel.

A set idea is never evidence that A → B mixes well. `live-mixing.md` remains the separate performance layer when actual mix planning is requested and evidence exists.

## Maintenance rules

1. Keep this file small and useful; prefer a few strong directions over a catalogue dump.
2. Add a new idea only when discovery creates a materially different creative direction.
3. Merge overlapping ideas instead of proliferating near-duplicates.
4. Never convert a set idea into a canonical playlist change automatically.
5. Never claim transition quality, harmonic compatibility, phrase fit, or energy match without evidence.
6. A canonical REJECT may remain an excellent set-inspiration ingredient when the rejection was placement-specific.
7. A PARKED or TRIGGERED REVISIT may be used as inspiration without itself proving canonical fit.
8. Do not ask the user to curate or maintain this file. The engine owns the housekeeping.
