# Unified Journey Site Subsection Brief — STRANGE GAIT

STRANGE GAIT is a read-only subsection of the single published editorial journey site:

`https://broskmenmi.github.io/editorial-engine/`

Do not create or maintain a separate playlist-specific website or hostname.

## Source of truth

Render from generated `playlists/strange-gait/journey-map.json` and obey repository-root `FELT-VISUALIZATION-DOCTRINE.md` plus this volume's `journey-map-spec.md`.

GitHub remains authoritative. The site must never edit the ledger, make editorial decisions, or publish Spotify.

## Default experience

The primary visualization is **Felt**, not the legacy story-height chart.

Offer four views:

1. **Feeling** — qualitative state/direction with provenance;
2. **Groove** — pulse, swing, rhythmic stability, density and weight only where evidenced;
3. **Structure** — chapter, role, mutation, interruption, arrival/release and playlist-specific story vocabulary;
4. **Tempo** — BPM/duration metadata kept separate.

Selecting a track shows its direction, evidence class, two-before/two-after window where available, whole-playlist position and a concise techno-learning explanation.

Unknown dimensions remain explicitly unknown.

## STRANGE GAIT structure vocabulary

Ground / Tilt / Lock / Fracture / Deep Lock / Escape remain optional secondary editorial language only. Do not present them as a required journey or as measured energy.

## Shared-site behaviour

- one global shell and canonical root URL;
- independent playlist JSON loads;
- failure of another playlist does not suppress STRANGE GAIT;
- phone-first, tap-first interaction;
- exact canonical order preserved;
- track list remains available and collapsible.

## Evidence labels

Clearly distinguish listener report, measured audio, attributed source description, editorial interpretation and unknown.

BPM/duration are metadata. Never claim waveform, energy, loudness, mood, microtiming, swing, density, tension or mixability without supporting evidence.

## Visual identity

Graphite-black field, off-grid architectural lines, bone/steel type, bruised-violet directional accents and sparse oxidized-copper unresolved markers. No neon, equalizer graphics, literal feet or generic SaaS dashboard styling.
